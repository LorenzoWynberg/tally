# App structure

`index.html` holds the whole DOM shell: a visually-hidden `<h1>`, the `#today` date paragraph right below the title, the count (`#count`, inside a visually-hidden-labelled `<p class="count">`), an `.actions` row, the `#reset-button`, and the `#live-region` paragraph (`aria-live="polite"`, `aria-atomic="true"`, visually hidden). It carries a `Content-Security-Policy` meta tag restricting sources to `'self'` (plus `data:` for images) and disabling form submission.

The `.actions` row holds, in order: the `#subtract-one-button` (labelled "Subtract one" via `aria-label`; its visible text is "−1", the U+2212 minus sign — unlike `#tap-button` and `#add-five-button`, this button's accessible name does not include the glyph), the `#tap-button` (labelled "+1, add one" via `aria-label`, the visible glyph included in the accessible name to satisfy WCAG 2.5.3 Label in Name), and the `#add-five-button` (labelled "+5, add five"). `#subtract-one-button` is sized identically to `#add-five-button` (both fixed to the `--control-min-touch` token) so `#tap-button` sits flanked by two equal-width elements and its bounding-box center stays exactly on the viewport's horizontal center regardless of which flanking button is pressed. `#subtract-one-button` carries `aria-disabled` (never the native `disabled` attribute) so it stays focusable and in the tab order even while the count is 0 — a natively disabled button would drop focus to `<body>` on the press that brings the count to 0.

`app.js` is a single IIFE that queries these elements by id, wires `click` listeners on all three buttons, renders the current count into `#count` on load and after every change, and renders today's date into `#today` once on load via `renderDate()`. `renderDate()` formats `new Date()` with `Intl.DateTimeFormat(undefined, { day: "numeric", month: "long", year: "numeric" })` — the visitor's own locale and timezone — and sets `#today`'s `lang` attribute to `formatter.resolvedOptions().locale` before writing the text, so a locale other than the page's hardcoded `<html lang="en">` is still announced correctly by a screen reader. It has no module system and no build step: the file served by GitHub Pages is the file in the repo.

`styles.css` is the only stylesheet; see [design tokens](../../rules/design-tokens.md) for how it is organized around `DESIGN.md`'s roles and scales rather than literal values.

For how the count itself is held, persisted and synced, see [counter state](counter-state.md).
